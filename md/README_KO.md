# 서울 지하철 2·5호선 전처리 데이터

이 폴더는 업로드된 서울교통공사 원본 CSV 중 2호선·5호선에 필요한 정보를 전처리한 결과입니다. 9호선 데이터는 아직 매핑 중이므로 참고바랍니다.
## 생성 파일

| 파일 | 내용 |
|---|---|
| `processed/stations.csv` | 그래프 정점. 노선 및 지선별 고유 `node_id`, 표준 역명, 요금표 역번호 포함 |
| `processed/segments.csv` | 일반 열차 이동 간선. 시간(초), 거리(m), 원본 행 번호 포함 |
| `processed/transfers.csv` | 노선 환승 및 동일 노선 지선 연결 간선 |
| `processed/graph_edges.csv` | `segments.csv`와 `transfers.csv`를 합친 그래프 입력용 통합 간선 |
| `processed/fare_station_mapping.csv` | 2·5호선 역과 운임표 역번호 매핑 |
| `processed/fare_od_2_5.csv` | 2·5호선 매핑 역번호끼리의 OD 운임표 부분집합 |
| `processed/quality_checks.csv` | 건수, 매핑, 연결성 검사 결과 |
| `processed/preprocessing_report.txt` | 전처리 가정과 검사 요약 |

## 생성 결과

- 역 정점: 110개
- 일반 이동 간선: 214개(방향별 간선)
- 환승·지선 연결 간선: 18개(방향별 간선)
- 운임표 매핑: 107개 노선-역 항목, 106개 고유 운임 역번호
- 2·5호선 운임 OD 행: 11,236개
- 그래프 연결성: 110개 정점 모두 하나의 연결 그래프에서 도달 가능

## 실행 방법

Python 3 표준 라이브러리만 사용합니다.

```bash
python src/preprocess_2_5.py
```

실행 결과는 `processed/`에 다시 생성됩니다. 원본 CSV는 `raw/`에 보존되어 있습니다.

## 전처리 기준 및 주의사항

1. **2호선 순환선**: 원본의 첫 시청역부터 마지막 시청역까지를 순환 경로로 처리합니다. 마지막 시청역 행은 새 정점이 아니라 순환을 닫는 간선으로 사용합니다.
2. **2호선 지선**: 성수-용답-신답-용두-신설동, 신도림-도림천-양천구청-신정네거리-까치산으로 분리합니다.
3. **5호선 분기**: 방화에서 천호까지의 구간 이후 강동에서 하남 방면과 마천 방면으로 분기합니다.
4. **분기 정점 구분**: 같은 물리적 역이라도 지선 상태가 다른 분기점은 서로 다른 `node_id`로 둡니다. 지선 간 이동은 환승 자료의 동일 노선 연결 시간·거리로 별도 표현합니다.
5. **양방향 처리**: 역간 소요시간 자료가 방향별로 나뉘어 있지 않아 원본 순서 방향을 기준으로 반대 방향 간선을 같은 시간·거리로 생성했습니다. `direction_inferred=true`가 이 가정을 표시합니다. 실제 방향별 시간 자료를 확보하면 교체해야 합니다.
6. **환승 처리**: 2↔5호선 환승은 원본 방향별 행을 사용합니다. 역방향 행이 없는 연결은 동일 시간·거리로 역방향을 추가하고 `direction_inferred=true`로 표시합니다.
7. **지선 연결 횟수**: `BRANCH_CHANGE`는 같은 노선 내 지선 상태 전환이므로 `transfer_count_increment=0`입니다. 실제 환승 횟수는 `LINE_CHANGE`만 1 증가시킵니다.
8. **운임표 매핑**: 운임표 역명 끝의 괄호 별칭을 제거해 이름을 맞추되, 노선별 운임 역번호 범위로 후보를 구분했습니다. 2호선 까치산은 물리적으로 공유하는 운임 역번호 2519로 연결했습니다. 이 매핑은 출처의 역번호 체계를 따른 것이며, 운영기관이 제공하는 별도 통합 역코드가 있다면 추후 대조해야 합니다.
9. **요금 사용**: `fare_od_2_5.csv`는 OD 운임 조회·검증용입니다. 이를 각 구간의 요금으로 간주해 더하면 안 됩니다. 알고리즘에서 경로별 요금을 산정할 때는 전체 이동거리와 적용 운임 정책을 기준으로 계산하거나 공식 운임 조회값으로 검증해야 합니다.
10. **범위**: 9호선과 2·5호선 이외의 노선 연결은 제외했습니다. 따라서 다른 노선으로 갈아타는 경로는 이 그래프에서 탐색할 수 없습니다.
11. **기준일**: 역간 자료(파일명 기준 2024-08-10), 환승 자료(2026-08-31), 운임표(파일명 기준 2025-06-28)의 기준 시점이 서로 다릅니다. 결과 보고서에는 이 차이를 명시해야 합니다.

## 그래프 로딩 예시

```python
import csv
from collections import defaultdict

adj = defaultdict(list)
with open("processed/graph_edges.csv", encoding="utf-8-sig", newline="") as f:
    for row in csv.DictReader(f):
        adj[row["from_node"]].append({
            "to": row["to_node"],
            "time_sec": int(row["travel_time_sec"]),
            "distance_m": int(row["distance_m"]),
            "edge_type": row["edge_type"],
            "transfer_count_increment": int(row["transfer_count_increment"]),
        })
```
